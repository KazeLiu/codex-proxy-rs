# v3.30.0

## 升级说明

- 前后端需同步更新。管理 API 的账号额度窗口由 `windowLabelDisplay` 改为 `windowKind`，趋势摘要由 `label` 改为 `metric`，展示文案由前端按语言生成；自行对接这些字段的客户端需同步适配
- 用量请求明细改用 `clientApiKeyName`、`accountName` 和 `model` 按字面包含筛选，移除旧的通用 `search` 及其他未保留的筛选参数；汇总与洞察仅按时间和 Provider 筛选。自定义管理 API 调用方请按本版 API 文档调整参数
- 诊断导出接口改为返回 ZIP，包内包含 `diagnostics.json`、`summary.txt` 和 `README.txt`；直接消费原 JSON 下载响应的工具需改为解包读取

## 新功能

- 管理端与 Key 用量页支持简体中文、繁體中文和 English，切换后同步更新表格、图表、通知、共享组件与主题预览，并保存语言选择
- 诊断包补充请求输入与最终准备发送正文的指纹、上游终态用量和网关归集值，为关键事件保留采集预算，并明确标记缺失或截断的证据，便于排查缓存、用量与重试问题
- API 密钥创建、配置和列表操作统一使用客户端导入弹窗，提供 CC Switch 导入入口及项目链接

## 修复与调整

- OpenAI 出站会话、窗口和缓存关联标识按选中账号稳定隔离，剥离客户端 trace；轮次 ID、父子轮次引用和续接引用保留客户端原值
- Live 语音引导、sideband 与挂断转发业务扩展头，保留 `X-Session-Id`、`Voice-Session-Id` 及通话归属；追踪标识按账号隔离，HTTP 业务头保留重复值和原始字节
- 修复位置覆盖在跨日、续接或重放时刷新历史上下文日期的问题，保留原日期，仅调整时区和搜索位置
- 调整新建的工作区隐私预设，仅改写附加元数据中的用户名和 Git 远端命名空间，保留项目名与工具执行路径；已有自定义规则保持原配置
- 修复 SSE / WebSocket 流内 404 请求错误被误判为路径封禁、进而重试换号或将账号标为凭据无效的问题
- 完善取消期间的请求证据与插件中间件处理边界；备份创建、删除请求与审计记录原子写入，账号分组变更保留已提交结果，重启受理后阻止并发更新、回滚和重复重启
- 统一管理端流式请求和插件页面的会话恢复，身份切换后取消迟到响应，及时清理失效的 API 密钥明文
- 优化用量汇总、请求计数、账号额度和冷却状态查询，减少重复数据库读取；统一管理端与 Key 用量页的字段筛选，并调整表格间距、菜单、统计卡片和窄屏布局
- 更新 DOMPurify、`ctutils`、`chacha20` 和 `wnaf` 等依赖，修复已知安全问题并移出已撤回的依赖版本
